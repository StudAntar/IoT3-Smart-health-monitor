# IoT3---Smart-health-monitor

## Workflow
- Alle puller de seneste changes hver morgen efter daily scrum.
- Vi udvikler på feature branches.
- Alle ændringer merge's via Pull Requests.
- GitHub Actions CI kører automatiske tests på hver PR.
- Main branch er beskyttet og må ikke ændres direkte.

## Tests
Projektet bruger pytest, og CI kører automatisk tests på hver Pull Request.
